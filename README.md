# APS Concept V9 | FIELDWORK

A clean-slate, light-first editorial fieldwork concept. This is a development prototype, not a production release.

## Design

- Permanent left navigation rail on desktop, compact mobile header
- Field survey and tract-inspired custom vector graphics
- Warm mineral background, evergreen ink, terracotta accent (three base colors)
- Original detailed service descriptions and scope lists recovered from supplied source material
- Two-row client marquee; no external links until each destination and permission/implication are reviewed
- Existing interactive US map preserved as separate script
- Project form prepares an email; it does not send data to a server

## Run

Serve the folder with a local static server (`python3 -m http.server 8000`) and visit http://localhost:8000. Test mobile, desktop, email, and map.

## Prelaunch

Verify rewritten statements, client relationships, leadership titles, historic claims, form behavior, canonical URL configuration and all SEO metadata. Add Organization structured data only with confirmed facts. Confirm Cloudflare clean URL handling and redirects. Production remains untouched.
